REDPEN - GOLD/KROM SVG METAL FACE

Bu sürümde gold/krom render yöntemi değiştirildi.

ESKİ:
HTML <strong>
+ background-clip:text
+ çok sayıda CSS override

YENİ:
SVG <text>
+ SVG <pattern>
+ texture doğrudan text fill

Yani texture artık gerçekten ön yüzün boyasıdır.

KORUNAN:
- Gold / krom texture
- font seçimi
- harf boyutu
- harf aralığı
- yazıyı sürükleme
- logo sürükleme / boyutlandırma
- gerçek tabela ölçüsü
- arkadan halo
- malzeme seçenekleri

GOLD/KROM:
- Ön yüzde procedural WebP reflection texture
- Arkada ayrı halo text layer
- Ayrı koyu yan/derinlik katmanları
- CSS ghost/pseudo highlight yok

DOSYALAR:
public/textures/gold-reflection-strong.webp
public/textures/chrome-reflection-strong.webp

NOT:
page.tsx eski metal deneme CSS'lerini artık import etmez.
Gold/krom için metal-svg-face.css kullanılır.
